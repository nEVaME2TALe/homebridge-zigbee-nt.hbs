# Aplicativo de teste


Foi criado um aplicativo com o comando:

```
npx create-expo-app events -t
```

O modelo escolhido foi o em branco com TypeScript.

Depois o servidor subiu com:

```
npm run start
```

Na tela do terminal, a opção escolhida foi a de Android, para abrir no aparelho.

Em seguida foi aberto o arquivo de entrada do aplicativo.
